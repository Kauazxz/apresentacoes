## Como está organizado

Convenção proposta, a confirmar com o primeiro material que entrar:

- uma pasta por apresentação, em minúsculas e sem acento (`nome-do-projeto/`);
- dentro dela, os arquivos da apresentação e um `README.md` curto dizendo para quem foi feita, quando e onde foi apresentada.

## Regras

- Nada de credencial, token ou senha aqui. O repositório vai para o GitHub.
- O GitHub recusa arquivo acima de 100 MB e avisa acima de 50 MB. Exporte em PDF ou comprima antes de versionar.
